# Changelog

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
project is pre-1.0 so minor bumps hold breaking changes.

## [Unreleased]

### Removed / renamed
- The project is renamed **rmp2 -> vmp**. Crate and binary are `vmp`
  (`vmp`, `vmp --daemon`), error prefixes `vmp: {e}` / `vmp daemon: {e}`,
  runtime files `vmp.sock` / `vmp.pid` / `vmp.log`, and the persisted state
  file is now `session.json`.
- Storage moves from one directory to an XDG layout (see below): config in
  `~/.config/vmp/`, library in `~/.local/share/vmp/`, state in
  `~/.local/state/vmp/`, sockets/pid in `$XDG_RUNTIME_DIR/vmp/`; each
  overridable with `VMP_CONFIG_DIR` / `VMP_DATA_DIR` / `VMP_STATE_DIR` /
  `VMP_RUN_DIR` (a spawned daemon inherits all four).

### Changed (breaking)
- Config is Lua, not TOML: nvim-style `~/.config/vmp/init.lua` created by the
  user (missing file = defaults; vmp never generates it) with `vmp.opt.*` for
  options/titles and `vmp.map.*` for keybindings; unknown options/actions and
  wrong types are rejected like nvim, `"none"` still unbinds, bindings merge
  over defaults, and `require()` resolves modules under
  `~/.config/vmp/lua/`. Lua 5.4 is embedded through mlua (vendored; no system
  lua dependency), the `toml` dependency is gone, and legacy config.toml
  loading/migration is removed - migrate the library DB by hand (see
  CONFIG.md).

### Fixed
- Pausing from the TUI no longer desyncs daemon/mpv state, and the status bar
  gained a `playing`/`paused` indicator.
- Daemon startup race: the pid file is written before the socket is
  announced.
- `enter_resume_loaded` resume path re-checks mpv liveness and falls back to
  a normal play + notify when the daemon's mpv handle is gone.
- A broken config now surfaces its full `invalid config:` message at
  startup instead of a generic `daemon did not start`: the TUI captures the
  spawned daemon's stderr to `$XDG_RUNTIME_DIR/vmp/daemon-err` and relays it
  verbatim when the daemon exits early, before unlinking the file.

### Changed
- A new `scripting/` subsystem owns the embedded Lua runtime: `config/` now
  holds only typed settings, and `Config::load` delegates evaluation to
  `vmp::scripting::eval_config` (`config/lua_host.rs` moved to
  `scripting/host.rs`). The Lua VM is still booted per evaluation and dropped
  after harvesting; `ScriptingError` is the scripting error type.
- Configuration is evaluated once per daemon start, not in every process:
  the daemon bakes the effective settings (`mpv_binary`, titles,
  `volume_step`, `seek_step`, keybinding map) into `Snapshot.config`
  (`proto::ConfigState`) and the TUI rebuilds its `Keymap`/titles from the
  snapshot pull instead of running Lua. Snapshot payloads without the new
  `config` field still parse.
- Restructured the crate into a library + thin binary split (`src/lib.rs` +
  slimmed `src/main.rs`) with zero behavior change.
- Domain modules became directories with `mod.rs` re-exports:
  - `daemon.rs` -> `daemon/{mod,server,client,dispatcher,snapshot,lifecycle}.rs`
    (`Daemon::run/serve` now return `Result<(), Error>`; `serve` takes explicit
    paths+config as an integration-test seam; `Connection` (TUI side) and
    `spawn_daemon` are re-exported from `daemon`)
  - `mpv.rs` -> `mpv/{mod,process,ipc,events,commands,properties}.rs`
  - `db.rs` -> `db/{mod,connection,schema,migrations,queries}.rs`
  - `config.rs` -> `config/{mod,settings,loader,validation,defaults}.rs` plus
    a new `scripting/{mod,host}.rs` for the Lua runtime
    (`Config::load` returns `Result<Self, Error>` and runs the Lua host)
  - `state.rs` -> `storage/{paths,state}.rs` (`Paths::for_root` test seam)
  - `ui/` -> `ui/{app,mod,input,layout,render,panes/{mod,filters,library,mini_queue,status}}.rs`
    (LineInput moved to `input.rs`, layout to `layout.rs`, the draw tree to
    `render.rs`, the Action enum now lives in `app/action.rs`)
- Extracted Vim-mode commands into `commands/{mod,parser,builtins}.rs`; the
  `unknown command` hint text is generated by `builtins::known_commands_hint`.
- Centralized shared error plumbing in `error.rs` and the epoch-ms/file log
  helpers in `logging.rs`.

### Added
- Full nvim-style ex-command set in `:` mode covering every keybind/click
  action: `:play [n]`, `:pause`/`:resume`/`:toggle`, `:stop`, `:next`/`:prev`,
  `:seek [+N|-N|M:SS]`, `:volume [+N|-N|N]`, `:repeat [off|all|one]`,
  `:shuffle [on|off]`, `:tag`, `:tags`, `:clear_tags`, `:search`, `:noh`,
  `:add [URI [TAGS]]` (quoted uris supported), `:edit`, `:delete [!]`,
  `:favorite`, `:mini [add|remove|up|down]`, `:up`/`:down`,
  `:pane [next|prev|NAME]`, `:help [keys|commands|NAME]`, `:settings`,
  `:theme`, `:transparency`, `:detach`. Commands resolve via unambiguous
  prefix matching (`:vol` -> `:volume`); ambiguous prefixes list candidates.
  New `commands/builtins.rs` catalog drives parsing, `:help commands` (two
  column usage dialog) and the unknown-command hint.
- Protocol commands `stop`, `set_repeat`, `set_shuffle` (additive; the ex
  commands `:stop`, `:repeat <mode>` and `:shuffle <on|off>` use them).
- Integration test suites under `tests/` (engine, protocol, config, storage,
  database, daemon e2e incl. a cross-process "daemon already running" check,
  and self-skipping mpv playback tests) plus a shared in-code WAV fixture
  module.
- `benches/engine.rs` (std-clock, no bench-harness dependency) with a
  `[[bench]]` Cargo entry.
- Repo tooling: `rust-toolchain.toml` pin, `rustfmt.toml`, `.editorconfig`,
  `scripts/check.sh`, `scripts/test.sh`, GitHub CI and release workflows,
  issue/PR templates, `docs/` (architecture, development, testing,
  configuration, protocol), CONTRIBUTING.md, SECURITY.md.
- Development log routing moved to `logging.rs` without changing the log line
  format (`[epoch-ms] message`).
- `enter_resume_loaded` config key (default `true`): `Enter` on the
  already-loaded selected track resumes playback instead of reloading it.

### Fixed
- Clippy gating surfaced two latent warnings (unused lifetime in
  `default_bindings`, missing `Default` for `SettingsState`); both are
  fixed without behavior change.
